# Eight Vision — versão auditada

Arquivos:
- index.html
- style.css
- script.js

## Como testar
1. Abra a pasta no VS Code.
2. Abra `index.html` no navegador (ou use Live Server).
3. Teste o menu em largura mobile, os links, a navegação por teclado e o Console do navegador.

## Alterações incluídas
- HTML limpo, com links de fontes e redes sociais em URLs válidas.
- Link "Pular para o conteúdo principal".
- Estilos visíveis de foco por teclado.
- Animações `.reveal` com aprimoramento progressivo: conteúdo visível se JavaScript falhar.
- Tratamento para navegadores sem `IntersectionObserver`.
- Menu móvel com `aria-controls`, rótulo dinâmico, Escape e foco devolvido ao botão.
- CSS responsivo e suporte a `prefers-reduced-motion`.
