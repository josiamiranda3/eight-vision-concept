# Eight Vision — Projeto Conceitual

Landing page conceitual desenvolvida como demonstração técnica para um processo seletivo de Desenvolvedor Front-end Júnior.

> **Aviso:** este é um projeto independente e não representa o site oficial da Eight Vision. A identidade visual e o conteúdo foram criados para fins demonstrativos.

## Sobre o projeto

O objetivo é apresentar uma proposta de página institucional para uma empresa de tecnologia, com foco em desenvolvimento de software e soluções digitais. O projeto utiliza tecnologias front-end fundamentais, sem exigir ferramentas de compilação.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela
- Navegação principal e menu móvel
- Seções de apresentação, soluções, sobre, processo e contato
- Animações de entrada com suporte a preferência por movimento reduzido
- Melhorias de acessibilidade, incluindo foco visível e navegação por teclado
- Atualização automática do ano no rodapé

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/josiamiranda3/eight-vision-concept.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd eight-vision-concept
   ```

3. Abra `index.html` no navegador ou abra a pasta no Visual Studio Code e execute o arquivo com a extensão **Live Server**.

Não é necessário instalar dependências ou executar um processo de build.

## Testes recomendados

- Verificar a navegação em desktop e dispositivos móveis
- Testar o menu com mouse e teclado
- Conferir links e ações de contato
- Abrir as ferramentas de desenvolvedor do navegador e verificar o Console
- Testar o layout em diferentes larguras de tela
